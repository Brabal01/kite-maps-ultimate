# GPX regression test tracks

OSRM itineraries from routing.openstreetmap.de (November 24, 2026).
The street and footpath geometry uses © OpenStreetMap contributors (ODbL).
See https://www.openstreetmap.org/copyright.

The timestamps are simulated. These fixtures contain no real device tracks or private locations.
Replay uses the same geometry as both the planned route and source of simulated GPS points,
with ±2 m of position noise. It checks route progress, arrival, and local driving side.
